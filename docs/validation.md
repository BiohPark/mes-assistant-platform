- `npm run build`: TypeScript 검사와 프로덕션 정적 빌드 통과.

- Prettier로 소스와 문서 포맷 정리.

테스트 범위: 체크리스트 미완료 차단, 선택한 산출물 참조만 인계, 원본·대화 보존, 잘못된 파일 참조 거부, 건너뛰기 사유, 되돌리기 후 재검토, 잘못된 전환 방향 차단, 대기 단계 되돌리기 거부, 후속 미완료가 있는 최종 완료 차단, 구조 편집 중 추가된 대화·파일 보존, 기록이 생긴 단계 삭제 차단.

## 브라우저에서 확인한 경로

- 목록 검색: `CIP` 검색 시 해당 업무 1개 표시.
- 업무 생성 → 7번째 단계 추가 → 수동 단계로 전환 → 저장.
- FDS 대화 입력 → 샘플 응답 → 산출물 저장.
- 미완료 체크리스트가 있는 상태에서 전환 시 안내와 함께 이동 차단.
- 체크 완료 후 산출물 두 개 중 한 개만 선택하여 개발 단계의 입력으로 인계.
- 수동 개발 메모 저장 → 새로고침 후 내용 복원.
- `docs/demo-evidence.txt` 업로드 → IndexedDB 저장 → 원문 미리보기 확인.
- 건너뛰기 시 빈 사유 차단 → 사유 입력 후 전환 → 사유를 남기고 URS로 복귀.
- 완료 단계의 체크박스 비활성화 및 대기 단계의 되돌리기 비활성화.
- 주별 → 일별, 담당자 김민서 필터 변경 시 활동/업무 집계 변화.
- 데스크톱 및 390px 모바일 화면 확인. 작은 화면의 자료/대화/체크리스트는 세로 배치.
- 검사한 화면의 브라우저 console error 없음.

## 다운로드 검증 범위

다운로드는 Blob URL과 브라우저의 표준 `download` 링크로 구현했습니다. UI 실행 중 콘솔 오류는 없었으나 Codex 내장 브라우저 자동화의 download 이벤트가 제한 시간 내 전달되지 않아 OS에 저장된 결과 파일까지 자동 확인하지는 못했습니다. 별도 Chrome 검사는 해당 테스트 탭 연결이 종료되어 완료하지 못했습니다. 실제 시연 환경의 Chrome/Edge에서 다운로드 저장 위치를 확인하는 최종 점검이 남아 있습니다.

## 리뷰 보완

1. 편집창이 열린 동안 들어온 대화/첨부가 스냅샷 저장으로 소실될 수 있었던 문제를 최신 단계 ID 기반 구조 병합으로 수정했습니다.
2. 아직 시작하지 않은 단계에서 되돌리며 진행 중 단계가 복수로 생기는 경로를 차단했습니다.
3. 완료 단계의 체크리스트 변경을 제한하고, 미리 열린 항목 추가 폼도 완료 이후 숨기며 최신 상태에서도 변경을 차단합니다.

## 범위 밖

실제 LLM 호출, 외부 업무시스템 연결, 서버 감사증적, 다중 사용자/다중 탭 충돌 해결, 인증·권한, 실제 GMP 프로세스 적합성, 실제 배포·DB 조회는 검증 대상이 아닙니다. 이 데모는 한 브라우저 탭에서 샘플 업무 흐름을 설명하는 용도입니다.
