# 검증 기록 — 2026-09-22

## 자동 검증

`npm test`: 20개 테스트 통과.

- 업무 상태·체크리스트·대화의 독립성, 완료 및 재개 사유
- 컨텍스트 스냅샷, 파일 버전, 원본 보관 및 연결 해제 후 보존
- 제거한 컨텍스트의 과거 전송 기록 자동 재첨부 방지
- 모델 우선순위와 실제 요청 본문, 텍스트 파일 내용 전달
- API 오류 시 샘플 응답으로 대체하지 않음 (fetch 모의 응답)
- 요청자 메시지·첨부 범위, 내부 응답 차단, 역할 전환 중 지연 응답 공개 방지
- SR 중복 접수 방지와 업무 상태 독립성, 태그의 접근 권한 비부여
- 폐기 에이전트 인계 차단과 원자적 처리
- 바이너리 및 과거 버전을 포함한 결과 내보내기, 누락 파일 오류

## 브라우저에서 직접 확인

- 갤러리에서 선택한 에이전트의 업무만 표시
- 검색어를 유지한 보드/목록 전환
- 메시지 1개와 파일 1개 선택 → 미리보기 → FDS 새 업무로 인계
- 대상 업무의 새 체크리스트·대화와 활성 컨텍스트 칩
- 샘플 assistant 호출 및 출처·모델·전송 컨텍스트 수 기록
- 연결 해제 후 활성 칩 제거, 대화·받은 자료 보존, 새로고침 복원
- 명시적인 결과 공유 후 요청자 화면에서 공유된 답변만 확인
- SR 초안 생성 → 지정된 URS 대화 → 명시적인 접수 버튼
- 접수번호·대화 태그·알림·요청 목록 동시 반영
- 대표 PNG 업로드·저장 후 새로고침 시 이미지 복원
- 1440px 데스크톱에서 갤러리 4열 시각 확인; 기본 좁은 화면에서 업무·SR 흐름 조작

## 미검증 및 범위

- 브라우저 도구 연결 종료로 이미지 교체·제거의 마지막 UI 재검증은 미완료. 코드에는 업로드/교체/제거/다운로드와 실패 시 이니셜 처리가 구현되어 있음.
- 사내 API 접속 정보가 없어 실제 사내 모델과의 통신은 미검증. 요청 구성과 오류 경로는 모의 fetch로 검증함.
- 본 데모는 브라우저 내부 저장 및 역할 화면 시연. 다중 PC 동기화·SSO·서버 권한 강제·GMP 운영 검증을 제공하지 않음.
- 브라우저 시연으로 생성한 검증용 업무와 SR은 로컬 데모 저장 공간에 남아 있음.
