# FlowMES Implementation Plan

**Goal:** 기존 대화형 assistant의 산출물 전달과 단계별 작업을 시연하는 로컬 프론트엔드 데모.
**Architecture:** React/TypeScript UI, 순수 상태 전환 함수, localStorage 메타데이터와 IndexedDB 파일 저장. 외부 API 없이 샘플 응답 사용.
**Tech Stack:** React, TypeScript, Vite, Lucide, Vitest.
**Spec:** ../../design.md

## Global Constraints

- 백엔드/실제 모델 호출/자동 배포 구현 없음.
- 기존 assistant 내부 워크플로우 변경 없음.
- 단계 세션과 산출물 원본 참조 보존.
- 사유 없는 건너뛰기/되돌리기 금지.
